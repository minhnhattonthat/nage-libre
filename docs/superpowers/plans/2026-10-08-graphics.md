# Graphics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Find every Japanese label baked into graphics resources and replace it with English rendered from the project's English glyphs, rebuilt through the existing compress / relocate / repoint pipeline.

**Architecture:**
- Small stdlib modules:
  - `tiles.py`: planar codec and PNG sheets
  - `resources.py`: resource table access
  - `labels.py`: English label renderer using the `fontgen` glyphs (stroke 1, outline 2, same as the original lettering)
- `gfxsurvey.py` renders every non-scene resource for inspection.
- `gfx/edits.json` lists the label replacements. `build.py` applies them and places the rebuilt resources after the scene blocks.

**Tech Stack:** Python 3.12 stdlib (`python -I`), unittest, existing `compress` / `decompress` / `fontgen` / `rom` / `romimage`, Mesen2 (`scripts/mesen/dump_screen.lua`, `goto.lua`).

**Spec:** `docs/superpowers/specs/2026-10-08-graphics-design.md`

## Global Constraints

- Python stdlib only; `python -I`; tests: `python -I -m unittest discover -s scripts`.
- Write Python containing `\x..` or `\n` literals with the Write/Edit tools, never bash heredocs.
- The resource table is at `RES_TABLE = 0x50000`: 3-byte LoROM pointers, 1328 entries (`0x530`). Scene resources are `0x30F-0x45B` and are handled by the text pipeline.
- An edited resource must decompress to exactly the original length. Only label tile areas may differ.
- Labels must fit the original tile area; no tilemap or layout changes.
- Command-menu English (≤ 40 px each): 待機 Wait, 攻撃 Attack, アイテム Item, 交換 Trade, ポケベル Pager, アニメ Anime, セーブ Save.

## Review Focus

1. **Greyed / palette variants:** greyed items (攻撃, 交換) reuse their own tiles under palette 1, so their English must use the same colour indices as the original. Otherwise greying breaks. Test: `test_render_uses_only_given_indices` (Task 3).
2. **2bpp vs 4bpp confusion:** a 4bpp resource edited as 2bpp corrupts the whole sheet. The `bpp` in `edits.json` must match. Test: `test_encode_decode_roundtrip_4bpp` (Task 1) and the length check in `test_gfx_edit_applied` (Task 4).
3. **Untouched tiles:** non-label tiles (the frame and header pieces in the same resource) must stay byte-identical. Test: `test_gfx_edit_applied` compares every non-label tile (Task 4).
4. **No edits = no change:** an empty `gfx/edits.json` must leave the build byte-identical. Test: `test_gfx_empty_edits_identical` (Task 4).
5. **Resources shared by several screens** (e.g. `0x28B` also matched one menu tile): an edit must not silently change unrelated screens. The survey records every resource where a label's tiles occur (Task 2). Edits apply only to the resource the inventory names.

```python
"""Resource table access: 3-byte LoROM pointers at RES_TABLE, nibble-compressed blocks (notes/text-engine.md)."""
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import decompress, rom

RES_TABLE = 0x50000
COUNT = 0x530
SCENES = range(0x30F, 0x45C)


def pointer(data, rid):
    return rom.lorom_to_pc(int.from_bytes(data[RES_TABLE + 3 * rid: RES_TABLE + 3 * rid + 3], "little"))


def load(data, rid):
    return decompress.decompress(data, pointer(data, rid))[0]


def compressed_len(data, rid):
    return decompress.decompress(data, pointer(data, rid))[1]
```

```python
"""SNES planar tiles (2bpp / 4bpp) <-> 8x8 colour-index grids, and greyscale PNG sheets."""
import struct, zlib

TILE = {2: 16, 4: 32}


def _plane_pair(b, off, y):
    return b[off + 2 * y], b[off + 2 * y + 1]


def decode(data, bpp):
    size, out = TILE[bpp], []
    for t in range(len(data) // size):
        base, tile = t * size, []
        for y in range(8):
            lo0, lo1 = _plane_pair(data, base, y)
            hi0, hi1 = _plane_pair(data, base + 16, y) if bpp == 4 else (0, 0)
            tile.append([((lo0 >> (7 - x)) & 1) | (((lo1 >> (7 - x)) & 1) << 1)
                         | (((hi0 >> (7 - x)) & 1) << 2) | (((hi1 >> (7 - x)) & 1) << 3) for x in range(8)])
        out.append(tile)
    return out


def encode(tiles, bpp):
    out = bytearray()
    for tile in tiles:
        planes = [bytearray(8) for _ in range(bpp)]
        for y in range(8):
            for x in range(8):
                for p in range(bpp):
                    planes[p][y] |= ((tile[y][x] >> p) & 1) << (7 - x)
        out += bytes(b for y in range(8) for b in (planes[0][y], planes[1][y]))
        if bpp == 4:
            out += bytes(b for y in range(8) for b in (planes[2][y], planes[3][y]))
    return bytes(out)


def sheet(tiles, cols=16, scale=2):
    rows = (len(tiles) + cols - 1) // cols
    w, h = cols * 8 * scale, rows * 8 * scale
    top = max((v for t in tiles for r in t for v in r), default=1) or 1
    raw = bytearray()
    for py in range(h):
        raw.append(0)
        ty, y = divmod(py // scale, 8)
        for px in range(w):
            tx, x = divmod(px // scale, 8)
            i = ty * cols + tx
            raw.append(tiles[i][y][x] * 255 // top if i < len(tiles) else 40)

    def chunk(kind, body):
        return struct.pack(">I", len(body)) + kind + body + struct.pack(">I", zlib.crc32(kind + body))
    return (b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", struct.pack(">IIBBBBB", w, h, 8, 0, 0, 0, 0))
            + chunk(b"IDAT", zlib.compress(bytes(raw))) + chunk(b"IEND", b""))
```

```python
"""Graphics survey: render every non-scene resource as 2bpp/4bpp tile sheets; locate VRAM tiles in resources.

    python -I scripts/gfxsurvey.py [--out work/gfx]
    python -I scripts/gfxsurvey.py --find work/mem/X_vram.bin 90 91 A0      # BG3 tiles (base byte 0xA000)
"""
import functools, os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import resources, rom, tiles


@functools.lru_cache(maxsize=1)
def _all(data):
    out = {}
    for rid in range(resources.COUNT):
        if rid in resources.SCENES:
            continue
        try:
            out[rid] = resources.load(data, rid)
        except Exception:
            continue
    return out


def candidates(data):
    return [(rid, len(b)) for rid, b in _all(bytes(data)).items() if b and len(b) % 16 == 0]


def find_tiles(data, tile_bytes):
    hits = []
    for rid, b in _all(bytes(data)).items():
        i = b.find(tile_bytes)
        while i >= 0:
            hits.append((rid, i))
            i = b.find(tile_bytes, i + 1)
    return hits


def main():
    d = rom.load()
    if "--find" in sys.argv:
        i = sys.argv.index("--find")
        vram = open(sys.argv[i + 1], "rb").read()
        for h in sys.argv[i + 2:]:
            t = int(h, 16)
            blob = vram[0xA000 + t * 16: 0xA000 + t * 16 + 16]
            print(f"tile {t:02X}:", [(f"{r:03X}", f"{o:#x}") for r, o in find_tiles(d, blob)] if any(blob) else "blank")
        return
    out = sys.argv[sys.argv.index("--out") + 1] if "--out" in sys.argv else os.path.join(rom.ROOT, "work", "gfx")
    os.makedirs(out, exist_ok=True)
    with open(os.path.join(out, "index.txt"), "w", encoding="utf-8") as idx:
        for rid, size in candidates(d):
            b = _all(bytes(d))[rid]
            for bpp in (2, 4):
                if len(b) % tiles.TILE[bpp] == 0:
                    with open(os.path.join(out, f"res_{rid:03X}_{bpp}bpp.png"), "wb") as f:
                        f.write(tiles.sheet(tiles.decode(b, bpp)))
            idx.write(f"{rid:03X} {size}\n")
    print(out)


if __name__ == "__main__":
    main()
```

```python
"""Render English labels for graphics tiles from font/en_glyphs.txt: proportional glyphs, 1 px spacing,
stroke = ink index, 8-neighbour outline = outline index (the original lettering uses 1 / 2)."""
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import fontgen

_GLYPHS = None


def _glyph(ch):
    global _GLYPHS
    if _GLYPHS is None:
        _GLYPHS = fontgen.load()
    rows = _GLYPHS.get(ord(ch))
    if rows is None:
        raise ValueError(f"no English glyph for {ch!r}")
    cols = [x for x in range(len(rows[0])) if any(r[x] == "#" for r in rows)]
    if not cols:                                  # space
        return [r[:3] for r in rows]
    return [r[cols[0]: cols[-1] + 1] for r in rows]


def _strokes(text):
    parts = [_glyph(c) for c in text]
    h = len(parts[0])
    return ["".join(p[y] + "." for p in parts)[:-1] for y in range(h)]


def width(text):
    return len(_strokes(text)[0]) + 2             # + outline on both sides


def fits(text, width_px):
    try:
        return width(text) <= width_px
    except ValueError:
        return False


def render(text, width_px, height_px=16, ink=1, outline=2):
    rows = _strokes(text)
    w = len(rows[0]) + 2
    if w > width_px:
        raise ValueError(f"label {text!r} is {w} px, area is {width_px} px")
    x0 = (width_px - w) // 2 + 1
    y0 = (height_px - len(rows)) // 2
    g = [[0] * width_px for _ in range(height_px)]
    for y, row in enumerate(rows):
        for x, c in enumerate(row):
            if c == "#":
                g[y0 + y][x0 + x] = ink
    for y in range(height_px):
        for x in range(width_px):
            if g[y][x] == 0 and any(g[yy][xx] == ink for yy in range(max(0, y - 1), min(height_px, y + 2))
                                    for xx in range(max(0, x - 1), min(width_px, x + 2))):
                g[y][x] = outline
    return g


def to_tiles(grid):
    h, w = len(grid) // 8, len(grid[0]) // 8
    return [[grid[ty * 8 + y][tx * 8: tx * 8 + 8] for y in range(8)] for ty in range(h) for tx in range(w)]
```
